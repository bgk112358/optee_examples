第一章：产品概述

1.1 产品定义

TBox 安全服务在设备主板上搭载一颗独立安全芯片（华大 CIU98B），通过芯片厂商 SDK 和自研交付库（libtbox_delivery.so）为上层应用提供以下核心安全能力：

  • 密钥安全存储：设备 RSA 私钥、证书、CA 链在芯片出厂时烧录，明文永不出芯片
  • 密码学运算：RSA 签名/验签、PKCS#1 解密等操作在安全芯片内部完成
  • TLS 双向认证：通过 HSM ENGINE + paho 回调注入将密钥操作接入 HTTPS 和 MQTTS 协议栈
  • 产线一机一密：每台设备的密钥和证书在芯片封测阶段烧录，工厂灌装仅做 PIN 设置和检查

1.2 核心价值

价值说明
密钥不出安全芯片私钥在安全芯片内生成和存储，全生命周期不离开芯片物理边界
标准协议兼容通过 OpenSSL HSM ENGINE + paho 回调注入，应用层无需适配
硬件信任根安全芯片自带真随机数发生器 (TRNG) 和防篡改保护
一机一密每台设备芯片内烧录唯一密钥，设备身份可认证、可追溯
车规级安全芯片通过 AEC-Q100 认证，支持 -40°C ~ 105°C 工作温度

第二章：安全架构

2.1 安全芯片架构

华大 CIU98B 安全芯片通过 SPI/I2C 总线与主 SoC 连接。芯片内部运行独立的固件，对外暴露 PKCS#11 风格的安全存储槽位和 HSM ENGINE 接口。

主 SoC (REE)安全芯片 (HSM)
处理器ARM Cortex-A / M 应用核心专用安全控制器
操作系统Linux芯片固件
密钥可见性仅公钥完整密钥材料
物理防护无防篡改 + 侧信道防护
通信接口—SPI / I2C

3.2 HTTPS 双向认证

应用通过 ConfigSSLWithHsm(ctx) 一次性注入芯片凭据，之后 TLS 握手中的私钥操作由 HSM ENGINE 在安全芯片内部完成：

SSL_CTX *ctx = SSL_CTX_new(TLS_client_method());
InitHsm();                       // 初始化安全芯片 + 加载 HSM ENGINE
ConfigSSLWithHsm(ctx);           // 注入设备证书 / 私钥(ENGINE引用) / CA 链
SSL *ssl = SSL_new(ctx);
SSL_connect(ssl);                // TLS 握手 — 签名在芯片内完成

3.3 MQTTS 双向认证

paho.mqtt.c 库通过补丁（SSLSocket_setExternalConfigCallback）支持外部 SSL 配置注入，回调中调用 ConfigSSLWithHsm：

InitHsm();
SSLSocket_setExternalConfigCallback(ConfigSSLWithHsm);

MQTTClient_create(&client, "ssl://broker:8883", "tbox-device", ...);

ssl_opts.privateKey = "__EXTERNAL_CONFIG__";   // 触发 paho 回调
MQTTClient_connect(client, &conn_opts);         // 回调中注入 HSM 凭据

MQTTClient_publishMessage(client, topic, &msg, &token);
MQTTClient_subscribe(client, topic, 1);

设备自带 Root CA → Sub CA → Device Cert 的完整信任链。Broker 证书由同一 Root CA 签发，设备侧验证 Broker 时只需信任 kCA 即可。

物理安全安全芯片自带防篡改保护，开盖自毁密钥
导出限制HSM ENGINE 设计上禁止导出明文私钥

第六章：运维与恢复

6.1 密钥生命周期

stateDiagram-v2 BURN: 芯片烧录
(封测厂) INIT: 设备初始化
(工厂) ACTIVE: 运营中 REVOKED: 已吊销
(KMS) DESTROYED: 物理销毁 [*] --> BURN: 生成密钥 + 签发证书 BURN --> INIT: 设备组装 INIT --> ACTIVE: 功能验证通过 ACTIVE --> REVOKED: 证书吊销 REVOKED --> DESTROYED: 芯片报废 DESTROYED --> [*]

与 OP-TEE 方案的关键区别：密钥不可在设备端生成或删除，更新只能通过更换芯片或 OTA 更新证书（不换密钥）。

6.2 故障排查

现象检查点
InitHsm 返回 -1芯片驱动是否加载 (lsmod | grep hed)，SPI/I2C 是否工作
ConfigSSLWithHsm 返回非 0芯片内证书槽位是否为空（生产烧录异常）
TLS 握手 "certificate verify failed"Broker 证书是否由芯片内 kCA 签发，时钟是否同步
paho 回调未触发privateKey 是否为精确字符串 "__EXTERNAL_CONFIG__"
paho 走文件路径trustStore/keyStore 不能与 __EXTERNAL_CONFIG__ 混用

6.3 设备退役

  1. 云端 KMS 吊销设备证书 → CRL/OCSP 生效
  2. 安全芯片无需额外操作（私钥永不出芯片，物理报废即销毁）
  3. 审计日志记录吊销操作
